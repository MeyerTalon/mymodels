# Push

After completing its task, use github to add commit and push all changes with a descriptive commit message.

If no other instruction is provided and only the push command is given, push up all local changes following the same instructions.

The agent should never name itself or give itself credit for the commit.

## Rules

- If this skill is attached to other work: run this **only after** that work is finished (or there is nothing left to do except ship).
- If the user only invokes push (e.g. `/push`) with no other task: immediately add, commit, and push **all** local changes.
- If there are **no changes** to commit, do not create an empty commit; say so briefly and stop.
- Do **not** update git config.
- Do **not** use `--no-verify`, force push, or rewrite history unless the user explicitly asks.
- Do **not** put the agent name, model name, "AI", "Cursor", "Generated by", "Co-authored-by" for the agent, or any self-credit in the commit message, body, or PR text.
- Write the commit message as a normal human contributor would: focus on **why**, keep it **concise** (preferably one short sentence, at most 1–2), match the repo's existing commit style when possible.

## Workflow

1. Inspect state in parallel:
   - `git status`
   - `git diff` (staged and unstaged)
   - `git log -5 --oneline` (style reference)
   - Check branch tracking / ahead-behind vs remote
2. Stage all local changes that belong in this ship (`git add -A` or equivalent for the relevant paths). Do not commit secrets (`.env`, credentials, private keys).
3. Commit with a concise HEREDOC message:

```bash
git commit -m "$(cat <<'EOF'
Concise descriptive message here.

EOF
)"
```

4. Push the current branch to GitHub (`git push -u origin HEAD` if upstream is missing, otherwise `git push`). Prefer `gh` for any GitHub-specific follow-ups the user asked for.
5. Confirm with `git status` and report the commit hash / remote result briefly.

## Commit message

- Concise
- Descriptive of the completed task or the local changes being pushed
- No self-attribution
- No trailing attribution footers from the agent
